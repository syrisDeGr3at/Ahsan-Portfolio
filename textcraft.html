Textcraft

Repeat the workflow. Skip the repetition.

A configurable text-cleanup tool that turns repetitive editing into a reusable sequence of rules. Preview the output, copy it, or download a text file.

Open working app ↗Clean / Transform / Reuse — messy text, beautifully organised.
JavaScriptRule-based automationText export
The idea

A small tool. A clear purpose.

Cleaning lists by hand takes repeated edits: remove blanks, tidy spaces, find duplicates. Textcraft applies selected operations in a consistent order and keeps the result visible beside the input.

The application runs directly in the browser with no account required. Its scope is deliberately focused on an everyday workflow visitors can try immediately.

How it works

From input to useful output.

01

Input

Paste a list, notes or other plain text into the input area.

02

Configure

Choose whitespace cleanup, lowercase conversion, blank-line removal, deduplication, sorting or bullets.

03

Run

Apply the selected rules and compare input and output character counts.

04

Use

Copy the result or export a text file. A session history records the latest five runs.

Implementation

Simple interactions. Visible results.

Semantic HTML provides the structure, responsive CSS adapts the layout, and JavaScript handles the application state and interactions. Exports are generated locally in the browser.

Data and scope. Text is processed locally using deterministic rules, with no AI model or server request. Run history lasts for the current session; download any output you want to keep.

A practical walkthrough

Choose the rules. Inspect the result.

01

Start with a repeated task

Paste a list with extra spaces, blank lines or repeated entries. Keeping the original beside the result makes the transformation easier to review.

02

Select only useful changes

Turn on whitespace cleanup, empty-line removal or deduplication as needed. Sorting, lowercase and bullets are optional operations for different outputs.

03

Review before you reuse

Run the workflow and inspect the result. Copy it or download a text file; recent runs appear in the session history. These are deterministic rules, not AI-generated text.
