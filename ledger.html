Ledger

Make everyday spending visible.

A lightweight expense tracker with category filters, a visual spending breakdown and CSV export. Designed around quick entries and understandable totals.

Open working app ↗Track / Understand / Export — your everyday spending, in perspective.
JavaScriptData visualisationCSV export
The idea

A small tool. A clear purpose.

A list of transactions is useful only when it tells a clear story. Ledger groups everyday expenses and turns the current view into totals and category comparisons.

The application runs directly in the browser with no account required. Its scope is deliberately focused on an everyday workflow visitors can try immediately.

How it works

From input to useful output.

01

Record

Enter a description, positive amount, date and spending category.

02

Explore

Filter the transaction list by category and see the summary update with it.

03

Understand

Compare category totals through a bar chart and percentage breakdown.

04

Export

Download the filtered records as CSV for use in a spreadsheet.

Implementation

Simple interactions. Visible results.

Semantic HTML provides the structure, responsive CSS adapts the layout, and JavaScript handles the application state and interactions. Exports are generated locally in the browser.

Data and scope. Expenses stay in local storage on the current browser and device. Clearing browser data removes them; exports provide a portable copy. There is no account sync or shared workspace.

A practical walkthrough

From individual entries to a clearer picture.

01

Capture the essentials

Add a description, a positive amount in PKR, a date and a category. Small, consistent entries make the transaction list easier to review later.

02

Read the current view

Choose a category to narrow the records. Compare the filtered total with the category breakdown; the chart describes the entries in the selected view.

03

Take the data with you

Export the filtered records as CSV. The application uses local browser storage and does not connect to a bank or move data between devices.
